API Reference

Base URL: http://127.0.0.1:8000

POST /pastes

Create a new paste. Returns the paste ID on success.

Request Body JSON

{
  "data": "string  (required) — content of the paste",
  "duration": "number (required) — lifetime in hours (e.g. 1, 24, 72, 168)",
  "id": "string (optional) — custom 6-char alphanumeric ID, auto-generated if omitted"
}

Example

curl -X POST http://127.0.0.1:8000/pastes \
  -H "Content-Type: application/json" \
  -d '{"data": "hello world", "duration": 168}'

Responses

201 Created 
{ "id": "A1B2C3" }
400 Bad Request 
{ "error": "invalid paste data or id" }

Data is empty or ID contains invalid characters.

409 Conflict 
{ "error": "paste id already exists" }

The generated or custom ID collided with an existing paste.

GET /pastes/{paste_id}

Retrieve the raw text content of a paste.

Path Parameters

paste_id — string — the 6-char paste ID

Example

curl http://127.0.0.1:8000/pastes/A1B2C3

Responses

200 OK 
hello world

Returns raw plain text, not JSON.

404 Not Found 
{ "error": "Not found File must have expired dummy!" }

Paste does not exist or has expired.
