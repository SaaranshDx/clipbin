API Reference

Base URL: https://api.ghostdrop.qzz.io

INFO Encryption

Encryption is optional. Encrypted content is supplied as the data string when creating a paste.

  • Content is encrypted with AES-256-GCM.
  • The key is derived with PBKDF2-SHA-256 using 250,000 iterations.
  • A random salt and initialization vector are generated for every paste.
  • The key is never sent to or stored by the API.

Encrypted data uses this JSON envelope:

{
  "version": 1,
  "algorithm": "AES-GCM",
  "kdf": "PBKDF2-SHA-256",
  "iterations": 250000,
  "salt": "base64",
  "iv": "base64",
  "ciphertext": "base64"
}
POST /pastes

Create a new paste. Returns the paste ID on success.

Request Body JSON

{
  "data": "string (required) — plaintext or encrypted JSON envelope",
  "duration": "number (required) — lifetime in hours (e.g. 1, 24, 72, 168)",
  "id": "string (optional) — custom 6-char alphanumeric ID"
}

Example

curl -X POST https://api.ghostdrop.qzz.io/pastes \
  -H "Content-Type: application/json" \
  -d '{"data":"hello world","duration":168}'

Responses

201 Created
{ "id": "A1B2C3" }
400 Bad Request
{ "error": "invalid paste data or id" }
409 Conflict
{ "error": "paste id already exists" }
GET /pastes/{paste_id}

Retrieve the raw text content of a paste.

Path Parameters

paste_id — string — the 6-char paste ID

Example

curl https://api.ghostdrop.qzz.io/pastes/A1B2C3

Responses

200 OK 
hello world

Returns raw text, not JSON. The X-Paste-Encrypted response header is true for encrypted pastes.

404 Not Found
{ "error": "paste not found" }
